🎯 What is WebDriver?

WebDriver is a browser automation API and a core component of Selenium. It provides a programming interface to create and execute test scripts that interact with web browsers. Unlike Selenium RC, WebDriver communicates directly with the browser using the browser's native support for automation, making it faster and more reliable.

🔑 Key Features of WebDriver

  • Direct Browser Communication: No need for JavaScript injection
  • Native Browser Support: Uses browser's built-in automation capabilities
  • Lightweight: Doesn't require a server to be running
  • Realistic Testing: Simulates real user interactions
  • Cross-Browser: Works with all major browsers

🛠️ Environment Setup

Step 1: Install Java

Selenium WebDriver requires Java Development Kit (JDK) to be installed.

Installation Steps:

  1. Download JDK from https://www.oracle.com/java/technologies/downloads/
  2. Install JDK and set JAVA_HOME environment variable
  3. Add Java to your system PATH
  4. Verify installation: java -version

Step 2: IDE Setup (Eclipse/IntelliJ)

Eclipse IDE:

  1. Download from https://www.eclipse.org/downloads/
  2. Choose "Eclipse IDE for Java Developers"
  3. Extract and launch Eclipse

IntelliJ IDEA:

  1. Download from https://www.jetbrains.com/idea/download/
  2. Install Community or Ultimate edition
  3. Launch IntelliJ IDEA

🚀 Your First Selenium Script

Basic Script - Opening a Browser

package com.automation.test;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;

public class FirstSeleniumTest {
    
    public static void main(String[] args) {
        // Initialize ChromeDriver
        WebDriver driver = new ChromeDriver();
        
        // Navigate to URL
        driver.get("https://www.google.com");
        
        // Get page title
        String title = driver.getTitle();
        System.out.println("Page Title: " + title);
        
        // Close browser
        driver.quit();
    }
}

✅ What This Script Does:

  1. Creates WebDriver instance: Initializes Chrome browser
  2. Navigates to URL: Opens Google homepage
  3. Gets title: Retrieves and prints page title
  4. Closes browser: Quits the browser and cleans up resources

⚙️ Browser Configuration

Window Management

// Maximize window
driver.manage().window().maximize();

// Minimize window (Selenium 4+)
driver.manage().window().minimize();

// Full screen
driver.manage().window().fullscreen();

// Set specific size
Dimension size = new Dimension(1024, 768);
driver.manage().window().setSize(size);

// Set position
Point position = new Point(100, 100);
driver.manage().window().setPosition(position);

Timeouts Configuration

import java.time.Duration;

// Implicit Wait - Wait for elements to appear
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

// Page Load Timeout - Wait for page to load
driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30));

// Script Timeout - For JavaScript execution
driver.manage().timeouts().scriptTimeout(Duration.ofSeconds(20));

Cookie Management

// Add cookie
Cookie cookie = new Cookie("username", "testuser");
driver.manage().addCookie(cookie);

// Get cookie
Cookie retrievedCookie = driver.manage().getCookieNamed("username");

// Get all cookies
Set<Cookie> allCookies = driver.manage().getCookies();

// Delete specific cookie
driver.manage().deleteCookieNamed("username");

// Delete all cookies
driver.manage().deleteAllCookies();

🧭 Navigation Methods

Method Description Example

🔚 Closing Browser

close() vs quit()

Method Behavior When to Use
driver.close() Closes current window/tab only When you have multiple windows and want to close only one
driver.quit() Closes all windows and terminates WebDriver session At the end of test execution (recommended) 
// Close current window
driver.close();

// Close all windows and quit
driver.quit();  // Recommended for cleanup

⚠️ Important:

  • Always use driver.quit() at the end of tests to free up system resources
  • Not calling quit() may leave browser processes running in background
  • Use try-finally or try-with-resources to ensure cleanup even if test fails

🏗️ BaseClass Implementation

A BaseClass provides reusable setup and teardown methods for all test classes. This is a best practice in test automation frameworks. 

package com.orangehrm.base;

import java.io.FileInputStream;
import java.time.Duration;
import java.util.Properties;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.edge.EdgeDriver;
import org.openqa.selenium.firefox.FirefoxDriver;
import org.testng.annotations.AfterMethod;
import org.testng.annotations.BeforeMethod;
import org.testng.annotations.BeforeSuite;

public class BaseClass {
    
    protected static Properties prop;
    protected static WebDriver driver;
    
    @BeforeSuite
    public void loadConfig() throws Exception {
        // Load configuration file
        prop = new Properties();
        FileInputStream fis = new FileInputStream(
            "src/main/resources/config.properties");
        prop.load(fis);
        System.out.println("Configuration loaded successfully");
    }
    
    @BeforeMethod
    public void setup() {
        // Initialize browser based on config
        String browser = prop.getProperty("browser");
        
        if(browser.equalsIgnoreCase("chrome")) {
            driver = new ChromeDriver();
        } else if(browser.equalsIgnoreCase("firefox")) {
            driver = new FirefoxDriver();
        } else if(browser.equalsIgnoreCase("edge")) {
            driver = new EdgeDriver();
        }
        
        // Configure browser
        driver.manage().window().maximize();
        driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30));
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
        
        // Navigate to application URL
        driver.get(prop.getProperty("url"));
    }
    
    @AfterMethod
    public void tearDown() {
        if(driver != null) {
            driver.quit();
        }
    }
}

Configuration File (config.properties):

# Browser Configuration
browser=chrome

# Application URL
url=https://opensource-demo.orangehrmlive.com/

# Timeouts
implicitWait=10
explicitWait=20
pageLoadTimeout=30

🎨 Browser Options

ChromeOptions - Advanced Configuration

ChromeOptions options = new ChromeOptions();

// Window settings
options.addArguments("--start-maximized");
options.addArguments("--window-size=1920,1080");

// Browser behavior
options.addArguments("--incognito");
options.addArguments("--disable-notifications");
options.addArguments("--disable-popup-blocking");
options.addArguments("--disable-extensions");

// Performance
options.addArguments("--disable-gpu");
options.addArguments("--no-sandbox");
options.addArguments("--disable-dev-shm-usage");

// Headless mode (no UI)
options.addArguments("--headless");

// Set download directory
Map<String, Object> prefs = new HashMap<>();
prefs.put("download.default_directory", "/path/to/download");
options.setExperimentalOption("prefs", prefs);

// Disable automation info bar
options.setExperimentalOption("excludeSwitches", 
    Collections.singletonList("enable-automation"));

// Initialize with options
WebDriver driver = new ChromeDriver(options);

Headless Browser Testing

// Chrome Headless
ChromeOptions options = new ChromeOptions();
options.addArguments("--headless");
options.addArguments("--disable-gpu");
WebDriver driver = new ChromeDriver(options);

// Firefox Headless
FirefoxOptions options = new FirefoxOptions();
options.addArguments("--headless");
WebDriver driver = new FirefoxDriver(options);

💡 When to Use Headless Mode:

  • CI/CD pipeline execution (Jenkins, GitHub Actions)
  • Running tests on servers without GUI
  • Faster test execution (no UI rendering)
  • Running multiple tests in parallel

🔄 WebDriver Manager

WebDriver Manager automatically downloads and configures browser drivers, eliminating manual driver management.

Add Dependency:

<dependency>
    <groupId>io.github.bonigarcia</groupId>
    <artifactId>webdrivermanager</artifactId>
    <version>5.9.2</version>
</dependency>

Usage:

import io.github.bonigarcia.wdm.WebDriverManager;

// Chrome
WebDriverManager.chromedriver().setup();
WebDriver driver = new ChromeDriver();

// Firefox
WebDriverManager.firefoxdriver().setup();
WebDriver driver = new FirefoxDriver();

// Edge
WebDriverManager.edgedriver().setup();
WebDriver driver = new EdgeDriver();

📱 Remote WebDriver

RemoteWebDriver allows running tests on remote machines or Selenium Grid. 

import org.openqa.selenium.remote.RemoteWebDriver;
import org.openqa.selenium.remote.DesiredCapabilities;
import java.net.URL;

// Set capabilities
DesiredCapabilities capabilities = new DesiredCapabilities();
capabilities.setBrowserName("chrome");
capabilities.setPlatform(Platform.WINDOWS);

// Connect to remote WebDriver (Selenium Grid)
WebDriver driver = new RemoteWebDriver(
    new URL("http://localhost:4444/wd/hub"), 
    capabilities
);

✅ Best Practices

  1. Always use driver.quit(): Ensures proper cleanup of resources
  2. Use configuration files: Externalize browser and URL settings
  3. Implement BaseClass: Centralize setup and teardown logic
  4. Set appropriate timeouts: Implicit and page load timeouts
  5. Maximize window: Ensures elements are visible and clickable
  6. Use WebDriver Manager: Simplifies driver management
  7. Use try-finally: Ensure cleanup even when tests fail
  8. Headless for CI/CD: Faster execution in automated pipelines

🐛 Common Issues & Solutions

1. SessionNotCreatedException

Cause: Version mismatch between browser and driver

Solution: Update browser driver or use WebDriver Manager

2. WebDriver executable not found

Cause: Driver not in system PATH

Solution: Set system PATH or use WebDriver Manager

3. Browser doesn't close after test

Cause: Not calling driver.quit()

Solution: Always call quit() in @AfterMethod or finally block
