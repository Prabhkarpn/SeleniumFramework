Performing Actions on Web Elements - Click, Type, Select, and More

🎯 What is WebElement?

A WebElement represents an HTML element on a web page. Once you've located an element using a locator strategy, you can interact with it using various WebElement methods. These interactions simulate real user actions like clicking, typing, selecting options, etc.

🔑 Common WebElement Operations:

  • Click buttons, links, checkboxes, radio buttons
  • Type text into input fields
  • Clear existing text from fields
  • Select options from dropdowns
  • Get element text, attributes, and properties
  • Check element state (displayed, enabled, selected)

1️⃣ click() - Clicking Elements

The click() method simulates a mouse click on an element.

// Click a button
WebElement loginButton = driver.findElement(By.id("login-btn"));
loginButton.click();

// Click a link
WebElement aboutLink = driver.findElement(By.linkText("About Us"));
aboutLink.click();

// Click a checkbox
WebElement agreeCheckbox = driver.findElement(By.id("agree-terms"));
agreeCheckbox.click();

// Click a radio button
WebElement maleRadio = driver.findElement(By.id("gender-male"));
maleRadio.click();

⚠️ Common Click Issues:

  • ElementNotInteractableException: Element is not visible or clickable
  • ElementClickInterceptedException: Another element is overlaying it
  • StaleElementReferenceException: Element is no longer in DOM

Solution: Use waits, scroll to element, or use JavaScript click

2️⃣ sendKeys() - Typing Text

The sendKeys() method types text into input fields.

// Type username
WebElement usernameField = driver.findElement(By.name("username"));
usernameField.sendKeys("admin");

// Type password
WebElement passwordField = driver.findElement(By.name("password"));
passwordField.sendKeys("admin123");

// Type email
WebElement emailField = driver.findElement(By.id("email"));
emailField.sendKeys("test@example.com");

// Append text to existing value
emailField.sendKeys(" - additional text");

// Send special keys
import org.openqa.selenium.Keys;

// Press Enter
usernameField.sendKeys(Keys.ENTER);

// Ctrl+A (Select All)
usernameField.sendKeys(Keys.CONTROL + "a");

// Copy (Ctrl+C)
usernameField.sendKeys(Keys.CONTROL + "c");

// Paste (Ctrl+V)
passwordField.sendKeys(Keys.CONTROL + "v");

// Tab to next field
usernameField.sendKeys(Keys.TAB);

3️⃣ clear() - Clearing Text Fields

The clear() method removes existing text from input fields.

// Clear existing text before typing new text
WebElement searchBox = driver.findElement(By.name("q"));
searchBox.clear();
searchBox.sendKeys("Selenium WebDriver");

// Best practice: Always clear before entering text
WebElement nameField = driver.findElement(By.id("name"));
nameField.clear();
nameField.sendKeys("John Doe");

4️⃣ submit() - Submitting Forms

The submit() method submits a form. Works on any element inside a form.

// Submit form by calling submit on any element in the form
WebElement usernameField = driver.findElement(By.name("username"));
usernameField.sendKeys("admin");

WebElement passwordField = driver.findElement(By.name("password"));
passwordField.sendKeys("admin123");

// Submit the form
passwordField.submit();  // OR usernameField.submit();

// Alternative: Click submit button
WebElement submitButton = driver.findElement(By.cssSelector("button[type='submit']"));
submitButton.click();

5️⃣ getText() - Getting Element Text

The getText() method retrieves the visible text of an element.

// Get text from element
WebElement heading = driver.findElement(By.tagName("h1"));
String headingText = heading.getText();
System.out.println("Heading: " + headingText);

// Get error message text
WebElement errorMsg = driver.findElement(By.className("error-message"));
String errorText = errorMsg.getText();

// Verify text
if(errorText.equals("Invalid credentials")) {
    System.out.println("Correct error message displayed");
}

// Get text from multiple elements
List<WebElement> listItems = driver.findElements(By.tagName("li"));
for(WebElement item : listItems) {
    System.out.println(item.getText());
}

6️⃣ getAttribute() - Getting Attributes

The getAttribute() method retrieves the value of an element's attribute.

// Get href attribute from link
WebElement link = driver.findElement(By.linkText("Google"));
String url = link.getAttribute("href");
System.out.println("URL: " + url);

// Get value from input field
WebElement inputField = driver.findElement(By.name("email"));
String fieldValue = inputField.getAttribute("value");

// Get class attribute
WebElement button = driver.findElement(By.id("submit-btn"));
String className = button.getAttribute("class");

// Get placeholder text
WebElement searchBox = driver.findElement(By.name("search"));
String placeholder = searchBox.getAttribute("placeholder");

// Check if attribute exists
String dataId = element.getAttribute("data-id");
if(dataId != null) {
    System.out.println("Data ID: " + dataId);
}

// Common attributes to retrieve
String id = element.getAttribute("id");
String name = element.getAttribute("name");
String type = element.getAttribute("type");
String value = element.getAttribute("value");
String title = element.getAttribute("title");

7️⃣ Element State Methods

isDisplayed() - Check Visibility

// Check if element is visible
WebElement loginButton = driver.findElement(By.id("login-btn"));
boolean isVisible = loginButton.isDisplayed();

if(isVisible) {
    loginButton.click();
} else {
    System.out.println("Button is not visible");
}

// Verify logo is displayed
WebElement logo = driver.findElement(By.className("company-logo"));
Assert.assertTrue(logo.isDisplayed(), "Logo should be visible");

isEnabled() - Check if Element is Enabled

// Check if button is enabled
WebElement submitButton = driver.findElement(By.id("submit"));
boolean isEnabled = submitButton.isEnabled();

if(isEnabled) {
    submitButton.click();
} else {
    System.out.println("Button is disabled");
}

// Check if input field is editable
WebElement inputField = driver.findElement(By.name("username"));
if(inputField.isEnabled()) {
    inputField.sendKeys("admin");
}

isSelected() - Check Selection State

// Check if checkbox is selected
WebElement checkbox = driver.findElement(By.id("remember-me"));
boolean isChecked = checkbox.isSelected();

if(!isChecked) {
    checkbox.click();  // Check the checkbox
}

// Verify checkbox state
Assert.assertTrue(checkbox.isSelected(), "Checkbox should be selected");

// Check radio button
WebElement radioButton = driver.findElement(By.id("gender-male"));
if(!radioButton.isSelected()) {
    radioButton.click();
}

8️⃣ Working with Dropdowns (Select Class)

For <select> dropdowns, Selenium provides a special Select class.

import org.openqa.selenium.support.ui.Select;

// Locate the dropdown
WebElement dropdown = driver.findElement(By.id("country"));

// Create Select object
Select select = new Select(dropdown);

// Select by visible text
select.selectByVisibleText("India");

// Select by value attribute
select.selectByValue("in");

// Select by index (0-based)
select.selectByIndex(2);

// Get selected option
WebElement selectedOption = select.getFirstSelectedOption();
System.out.println("Selected: " + selectedOption.getText());

// Get all options
List<WebElement> allOptions = select.getOptions();
System.out.println("Total options: " + allOptions.size());

// Print all options
for(WebElement option : allOptions) {
    System.out.println(option.getText());
}

// Check if dropdown supports multiple selections
boolean isMultiple = select.isMultiple();

// For multi-select dropdowns
if(isMultiple) {
    select.selectByVisibleText("Option 1");
    select.selectByVisibleText("Option 2");
    select.selectByVisibleText("Option 3");
    
    // Deselect specific option
    select.deselectByVisibleText("Option 2");
    
    // Deselect all
    select.deselectAll();
    
    // Get all selected options
    List<WebElement> selectedOptions = select.getAllSelectedOptions();
}

9️⃣ Checkboxes and Radio Buttons

Handling Checkboxes:

// Locate checkbox
WebElement agreeCheckbox = driver.findElement(By.id("agree-terms"));

// Check if already selected
if(!agreeCheckbox.isSelected()) {
    agreeCheckbox.click();  // Check it
}

// Uncheck if selected
if(agreeCheckbox.isSelected()) {
    agreeCheckbox.click();  // Uncheck it
}

// Toggle checkbox
agreeCheckbox.click();

// Select multiple checkboxes
List<WebElement> checkboxes = driver.findElements(By.cssSelector("input[type='checkbox']"));
for(WebElement checkbox : checkboxes) {
    if(!checkbox.isSelected()) {
        checkbox.click();
    }
}

Handling Radio Buttons:

// Select a radio button
WebElement maleRadio = driver.findElement(By.id("gender-male"));
if(!maleRadio.isSelected()) {
    maleRadio.click();
}

// Select from radio button group
List<WebElement> genderOptions = driver.findElements(By.name("gender"));
for(WebElement option : genderOptions) {
    if(option.getAttribute("value").equals("female")) {
        option.click();
        break;
    }
}

🎨 ActionDriver Implementation (Real Framework Example)

Based on your framework, here's how to create a reusable ActionDriver class:

public class ActionDriver {
    
    private WebDriver driver;
    private WebDriverWait wait;
    
    public ActionDriver(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }
    
    // Click method with wait
    public void click(By locator) {
        try {
            wait.until(ExpectedConditions.elementToBeClickable(locator));
            driver.findElement(locator).click();
            System.out.println("Clicked: " + getElementDescription(locator));
        } catch (Exception e) {
            System.out.println("Unable to click: " + e.getMessage());
        }
    }
    
    // Enter text method
    public void enterText(By locator, String text) {
        try {
            wait.until(ExpectedConditions.visibilityOfElementLocated(locator));
            WebElement element = driver.findElement(locator);
            element.clear();
            element.sendKeys(text);
            System.out.println("Entered text: " + text);
        } catch (Exception e) {
            System.out.println("Unable to enter text: " + e.getMessage());
        }
    }
    
    // Get text method
    public String getText(By locator) {
        try {
            wait.until(ExpectedConditions.visibilityOfElementLocated(locator));
            return driver.findElement(locator).getText();
        } catch (Exception e) {
            System.out.println("Unable to get text: " + e.getMessage());
            return "";
        }
    }
    
    // Check if displayed
    public boolean isDisplayed(By locator) {
        try {
            return driver.findElement(locator).isDisplayed();
        } catch (Exception e) {
            return false;
        }
    }
    
    private String getElementDescription(By locator) {
        // Implementation to describe element
        return locator.toString();
    }
}

📝 Page Object Model Example (LoginPage)

public class LoginPage {
    
    private ActionDriver actionDriver;
    
    // Locators
    private By usernameField = By.name("username");
    private By passwordField = By.name("password");
    private By loginButton = By.xpath("//button[@type='submit']");
    private By errorMessage = By.xpath("//p[text()='Invalid credentials']");
    
    public LoginPage(WebDriver driver) {
        this.actionDriver = new ActionDriver(driver);
    }
    
    // Login method
    public void login(String username, String password) {
        actionDriver.enterText(usernameField, username);
        actionDriver.enterText(passwordField, password);
        actionDriver.click(loginButton);
    }
    
    // Verify error message
    public boolean isErrorMessageDisplayed() {
        return actionDriver.isDisplayed(errorMessage);
    }
    
    public String getErrorMessageText() {
        return actionDriver.getText(errorMessage);
    }
}

✅ Best Practices

  1. Always clear() before sendKeys(): Removes existing text
  2. Use isDisplayed() before interactions: Verify element visibility
  3. Use isEnabled() before clicking: Check if element is clickable
  4. Use Select class for dropdowns: More reliable than sendKeys()
  5. Wait before interactions: Use explicit waits for stability
  6. Handle StaleElementReferenceException: Re-locate element if needed
  7. Create reusable methods: Wrap interactions in ActionDriver/utility classes
  8. Add descriptive logging: Track actions for debugging
  9. Verify action success: Check expected outcome after each action

🐛 Common Issues & Solutions

1. ElementNotInteractableException

Cause: Element is not visible or overlapped

Solution:

// Wait for element to be visible
wait.until(ExpectedConditions.visibilityOfElementLocated(locator));

// Or scroll to element
JavascriptExecutor js = (JavascriptExecutor) driver;
js.executeScript("arguments[0].scrollIntoView(true);", element);

2. ElementClickInterceptedException

Cause: Another element is covering the target element

Solution:

// Wait for element to be clickable
wait.until(ExpectedConditions.elementToBeClickable(locator));

// Or use JavaScript click
JavascriptExecutor js = (JavascriptExecutor) driver;
js.executeScript("arguments[0].click();", element);

3. StaleElementReferenceException

Cause: Element is no longer attached to DOM (page refreshed)

Solution:

// Re-locate the element
WebElement element = driver.findElement(locator);

// Or use try-catch and retry
try {
    element.click();
} catch(StaleElementReferenceException e) {
    element = driver.findElement(locator);
    element.click();
}
