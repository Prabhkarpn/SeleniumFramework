Most modern UIs (Salesforce Lightning, ServiceNow, Angular/React Material UI, Ant Design, PrimeNG) do not use the HTML <select> tag anymore. They render dropdowns as <div>, <ul><li> or <input role="combobox"> for styling flexibility. The classic Select class will not work on them.

1.2 Native <select> - The Easy Case

Use the Select class from org.openqa.selenium.support.ui.Select.

dropdown.selectByValue("2");
dropdown.selectByIndex(1);

// Useful APIs

System.out.println("Selected: " + dropdown.getFirstSelectedOption().getText());

How to confirm it is a native <select>:
Inspect element → if the tag name is literally select, use Select. If it is div, ul, input or anything else → it is a custom dropdown.

1.3 Custom div / ul / li Dropdowns (The Real-World Case)

The recipe is always 2 steps: Click to open → Wait & select the option.

💻 Live Example: https://demoqa.com/select-menu (React-Select "Select One" dropdown)

driver.get("https://demoqa.com/select-menu");

// The "Select One" dropdown on demoqa is a react-select widget (div-based)
By toggle = By.id("withOptGroup");  // the container div
By input = By.cssSelector("#withOptGroup input");

// Step 1: Click to open
driver.findElement(toggle).click();

// Step 2: Wait for options, click desired one via text
By option = By.xpath("//div[contains(@class,'option') and text()='Group 1, option 1']");
new WebDriverWait(driver, Duration.ofSeconds(10))
    .until(ExpectedConditions.elementToBeClickable(option)).click();

Generic Reusable Method

public void selectFromCustomDropdown(By dropdownToggle, By optionsLocator, String value) {
    WebDriver driver = BaseClass.getDriver();
    WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(15));

    // Step 1: open the dropdown
    wait.until(ExpectedConditions.elementToBeClickable(dropdownToggle)).click();

    // Step 2: wait for ALL options to render, then iterate
    List<WebElement> options =
        wait.until(ExpectedConditions.visibilityOfAllElementsLocatedBy(optionsLocator));

    for (WebElement option : options) {
        if (option.getText().trim().equalsIgnoreCase(value)) {
            option.click();
            return;
        }
    }
    throw new NoSuchElementException("Option [" + value + "] not found in dropdown");
}

1.4 Salesforce Lightning Combobox - The Famous One

In Salesforce Lightning the dropdown is rendered as:

<lightning-combobox>
   <input role="combobox" aria-controls="dropdown-element-7" aria-expanded="false"/>
   <div id="dropdown-element-7" role="listbox" style="display:none">
       <lightning-base-combobox-item data-value="hot"> Hot </lightning-base-combobox-item>
       <lightning-base-combobox-item data-value="warm"> Warm </lightning-base-combobox-item>
   </div>
</lightning-combobox>

Key differences:

  • The <input> is read-only — you cannot sendKeys. You must click to open.
  • Uses role="listbox" / role="option" (great locator hints).
  • aria-expanded flips false → true when opened. Use that as your wait condition.

Production Code for Salesforce Lightning

public void selectLightningCombobox(String label, String optionText) {
    WebDriver driver = BaseClass.getDriver();
    WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(20));

    // 1. Locate combobox via its label
    By combo = By.xpath(
        "//lightning-combobox[.//label[normalize-space()='" + label + "']]" +
        "//input[@role='combobox']");
    WebElement comboEl = wait.until(ExpectedConditions.elementToBeClickable(combo));
    comboEl.click();

    // 2. Wait for aria-expanded='true' (listbox is open)
    wait.until(ExpectedConditions.attributeToBe(comboEl, "aria-expanded", "true"));

    // 3. Click the option
    By option = By.xpath(
        "//lightning-base-combobox-item[.//span[normalize-space()='" + optionText + "']]");
    wait.until(ExpectedConditions.elementToBeClickable(option)).click();

    // 4. Verify selection
    wait.until(ExpectedConditions.attributeContains(comboEl, "value", optionText));
}

🎙 Interview Answer for "How do you handle Salesforce dropdowns?"

"Lightning components don't expose a real <select>; they render a div with role='combobox' and a portal listbox. I click the combobox, wait for aria-expanded='true', then click the option using role='option' or lightning-base-combobox-item. I never use the Select class for Lightning."

1.5 Auto-suggest / Typeahead Dropdowns

Behavior: You must type something first → AJAX returns suggestions dynamically.

💻 Live Example: https://demoqa.com/auto-complete

driver.get("https://demoqa.com/auto-complete");

WebElement input = driver.findElement(By.id("autoCompleteMultipleInput"));
input.sendKeys("re");  // triggers suggestions

// Wait for suggestion list
By suggestion = By.xpath(
    "//div[contains(@class,'auto-complete__option') and contains(text(),'Red')]");
new WebDriverWait(driver, Duration.ofSeconds(10))
    .until(ExpectedConditions.elementToBeClickable(suggestion)).click();

⚠️ Problem: Suggestion never appears in headless mode

Root Cause: Some sites debounce input — they fire AJAX only after 300ms of no typing.

Solution: Type character by character with a tiny pause:

for (char c : "sel".toCharArray()) {
    input.sendKeys(String.valueOf(c));
    Thread.sleep(80);  // or Actions.pause(Duration.ofMillis(80))
}

2.3 Find Row by Value & Click Action Button

Classic Interview Question: "Find the row where Last Name is 'Bach' and click its Edit link."

💻 Live Example: https://the-internet.herokuapp.com/tables

driver.get("https://the-internet.herokuapp.com/tables");

// Method 1: Direct XPath (find row with "Bach" in Last Name column and click edit)
By editLink = By.xpath(
    "//table[@id='table1']//tbody//tr[td[1][normalize-space()='Bach']]//a[text()='edit']");
driver.findElement(editLink).click();

// Method 2: Dynamic column index (production-grade)
public void clickActionInTable(String tableId, String colHeader, String cellVal, String action) {
    // Step 1: Find column index from header text
    List<WebElement> headers = driver.findElements(
        By.xpath("//table[@id='" + tableId + "']//thead//th"));
    int colIdx = -1;
    for (int i = 0; i < headers.size(); i++) {
        if (headers.get(i).getText().trim().equalsIgnoreCase(colHeader)) {
            colIdx = i + 1; break;  // XPath is 1-based
        }
    }

    // Step 2: Click action in the matching row
    By btn = By.xpath("//table[@id='" + tableId + "']//tbody" +
        "//tr[td[" + colIdx + "][normalize-space()='" + cellVal + "']]" +
        "//a[normalize-space()='" + action + "']");
    new WebDriverWait(driver, Duration.ofSeconds(10))
        .until(ExpectedConditions.elementToBeClickable(btn)).click();
}

// Usage:
clickActionInTable("table1", "Last Name", "Bach", "edit");

💡 Why Dynamic Column Index?

UI teams love to reorder columns. Hardcoding td[3] will break next sprint. Looking up the column by header name keeps the test stable across UI changes.

2.4 Dynamic Web Tables with PAGINATION

Real scenario: The value you need is NOT on the first page. It appears only when you click page 2 or 3.

💻 Live Example: https://demoqa.com/webtables

driver.get("https://demoqa.com/webtables");

// First, add enough entries to create pagination (or use a site with existing pagination)
// On DataTables: https://datatables.net/examples/basic_init/zero_configuration.html

driver.get("https://datatables.net/examples/basic_init/zero_configuration.html");

public boolean findAndClickAcrossPages(String searchName) {
    WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

    while (true) {
        // Search current page
        List<WebElement> rows = driver.findElements(By.cssSelector("#example tbody tr"));
        for (WebElement row : rows) {
            List<WebElement> cells = row.findElements(By.tagName("td"));
            if (cells.get(0).getText().trim().equalsIgnoreCase(searchName)) {
                // Found! Click or extract data
                System.out.println("Found: " + searchName + " on current page");
                return true;
            }
        }

        // Check if "Next" button is available/enabled
        WebElement nextBtn = driver.findElement(By.id("example_next"));
        if (nextBtn.getAttribute("class").contains("disabled")) {
            return false;  // Exhausted all pages
        }

        // Capture first row to detect page change
        String firstRowBefore = rows.get(0).getText();

        // Click Next
        nextBtn.click();

        // CRITICAL: Wait until page actually changes
        wait.until(ExpectedConditions.not(
            ExpectedConditions.textToBe(
                By.cssSelector("#example tbody tr:first-child"), firstRowBefore)));
    }
}

⚠️ Problem: StaleElementReferenceException after clicking Next

Root Cause: The DOM is completely rebuilt when you navigate pages. All previously located WebElements become stale.

Solution: NEVER cache WebElement references across pages. Always re-locate inside the loop using By locators.

⚠️ Problem: Loop scans same page twice (misses data)

Root Cause: After clicking Next, the AJAX call hasn't completed yet. The loop immediately re-scans the old page.

Solution: Wait until "first row text changed" OR "loading spinner disappeared" before re-scanning. This is the most common pagination bug in automation.

2.5 Infinite Scroll / "Load More" Tables

public boolean findInInfiniteScroll(String searchText) {
    JavascriptExecutor js = (JavascriptExecutor) driver;
    int previousCount = -1;

    while (true) {
        List<WebElement> rows = driver.findElements(By.cssSelector("table tbody tr"));

        // Search visible rows
        for (WebElement row : rows) {
            if (row.getText().contains(searchText)) {
                js.executeScript("arguments[0].scrollIntoView({block:'center'});", row);
                row.findElement(By.tagName("button")).click();
                return true;
            }
        }

        // If no new rows loaded, we've reached the end
        if (rows.size() == previousCount) return false;
        previousCount = rows.size();

        // Scroll last row into view to trigger lazy-load
        js.executeScript("arguments[0].scrollIntoView();", rows.get(rows.size() - 1));

        // Wait for new rows to appear
        int finalCount = rows.size();
        new WebDriverWait(driver, Duration.ofSeconds(5))
            .until(d -> d.findElements(By.cssSelector("table tbody tr")).size() > finalCount);
    }
}

3. Handling Frames / iFrames in Selenium

A frame / iframe is "a page inside a page". Selenium's driver only sees the top-level document by default. To interact with elements inside a frame, you must explicitly switch context into it.

3.1 Why iFrames Exist

  • Embedding 3rd-party widgets (Stripe/PayPal payments, reCAPTCHA, YouTube, Google Maps)
  • Sandboxing cross-origin content (Salesforce Visualforce, TinyMCE/CKEditor)
  • Module isolation in enterprise apps (ServiceNow, JIRA)

💡 Symptom that SCREAMS "frame!"

Your locator is correct (works in browser console), but Selenium throws NoSuchElementException. 9 times out of 10, the element is inside an iframe.

3.2 All Ways to Switch INTO a Frame

a) By index (least preferred)

driver.switchTo().frame(0);   // first iframe
driver.switchTo().frame(2);   // third iframe

b) By name or id attribute

driver.switchTo().frame("paymentFrame");  // matches id OR name

c) By WebElement (most reliable)

WebElement frameEl = driver.findElement(By.cssSelector("iframe[src*='payments']"));
driver.switchTo().frame(frameEl);

d) Wait + switch (RECOMMENDED)

new WebDriverWait(driver, Duration.ofSeconds(15))
   .until(ExpectedConditions.frameToBeAvailableAndSwitchTo(
        By.cssSelector("iframe[src*='editor']")));

3.3 Switching OUT of a Frame

driver.switchTo().parentFrame();    // goes 1 level up
driver.switchTo().defaultContent(); // jumps to top-level page (ALWAYS USE THIS)

3.4 Complete Working Example - TinyMCE Editor

💻 Live Example: https://the-internet.herokuapp.com/iframe

driver.get("https://the-internet.herokuapp.com/iframe");

// The TinyMCE editor surface is inside an iframe with id "mce_0_ifr"
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

// Step 1: Switch to the editor iframe
wait.until(ExpectedConditions.frameToBeAvailableAndSwitchTo(By.id("mce_0_ifr")));

// Step 2: Clear existing text and type new content
WebElement body = driver.findElement(By.tagName("body"));
body.clear();
body.sendKeys("Hello from Selenium Automation!");

// Step 3: ALWAYS come back to default content
driver.switchTo().defaultContent();

// Now you can interact with main page elements again
String heading = driver.findElement(By.tagName("h3")).getText();
System.out.println("Heading: " + heading);

3.5 Nested Frames Example

💻 Live Example: https://the-internet.herokuapp.com/nested_frames

driver.get("https://the-internet.herokuapp.com/nested_frames");

// Structure: frameset > frame[name='frame-top'] > frameset > frame[name='frame-middle']
// Switch to top frame first, then to middle
driver.switchTo().frame("frame-top");
driver.switchTo().frame("frame-middle");

String text = driver.findElement(By.id("content")).getText();
System.out.println("Middle frame text: " + text);  // "MIDDLE"

// Go back: level by level or straight to top
driver.switchTo().defaultContent();  // back to root

// Now switch to bottom frame
driver.switchTo().frame("frame-bottom");
String bottomText = driver.findElement(By.tagName("body")).getText();
System.out.println("Bottom frame text: " + bottomText);  // "BOTTOM"

driver.switchTo().defaultContent();  // ALWAYS come back

💡 Golden Rule

You cannot jump from one frame directly to a sibling frame. You must go up to defaultContent() first, then switch down to the sibling.

3.6 Reusable Framework Helper

/** Switch into a frame with explicit wait. */
public void switchToFrame(By by) {
    try {
        wait.until(ExpectedConditions.frameToBeAvailableAndSwitchTo(by));
        logger.info("Switched to frame: " + by);
    } catch (Exception e) {
        logger.error("Unable to switch to frame: " + e.getMessage());
    }
}

/** Always pair switchToFrame() with this in a finally block. */
public void switchToDefaultContent() {
    driver.switchTo().defaultContent();
    logger.info("Switched back to default content");
}

// Usage pattern (ALWAYS use try/finally):
try {
    actionDriver.switchToFrame(By.id("paymentFrame"));
    actionDriver.enterText(By.id("cardNumber"), "4111111111111111");
    actionDriver.click(By.id("payNow"));
} finally {
    actionDriver.switchToDefaultContent();
}

4. Waits in Selenium

Most flaky tests are caused by a missing or wrong wait. Modern web apps are asynchronous — AJAX calls, animations, SPA routing — so Selenium (which runs at JVM speed) often tries to interact with elements that don't exist yet.

4.1 Types of Waits

4.2 Implicit Wait

driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
// Applies to EVERY findElement call. Polls DOM every ~500ms.

Cons: Only checks DOM presence. Does NOT wait for visibility/clickability. Selenium docs warn against mixing with explicit waits.

4.3 Explicit Wait (WebDriverWait) - THE WORKHORSE

💻 Live Example: https://the-internet.herokuapp.com/dynamic_loading/1

driver.get("https://the-internet.herokuapp.com/dynamic_loading/1");

// Click "Start" button
driver.findElement(By.cssSelector("#start button")).click();

// Wait for loading to finish and text to appear
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(15));

// Wait for spinner to disappear
wait.until(ExpectedConditions.invisibilityOfElementLocated(By.id("loading")));

// Wait for result text to be visible

4.4 Fluent Wait

Wait<WebDriver> fluent = new FluentWait<>(driver)
    .withTimeout(Duration.ofSeconds(30))
    .pollingEvery(Duration.ofMillis(250))          // faster polling
    .ignoring(NoSuchElementException.class)
    .ignoring(StaleElementReferenceException.class) // ignore stale!
    .withMessage("Dashboard tile never loaded");

WebElement tile = fluent.until(d -> d.findElement(By.id("kpi-tile")));

💡 When to use FluentWait over WebDriverWait?

  • Need shorter polling interval (100-250ms instead of default 500ms)
  • Need to ignore StaleElementReferenceException (tables rebuilding)
  • Need a custom failure message

4.6 The Implicit + Explicit Trap

⚠️ NEVER Mix Implicit and Explicit Waits!

When explicit wait polls and hits findElement, the implicit wait ALSO kicks in for each poll. So WebDriverWait(10s) + implicit(10s) can take up to 100 seconds before timing out!

Fix: Set implicit wait to 0 and rely fully on explicit waits.

5. JavaScriptExecutor in Selenium

c) Set Value on Date Picker

💻 Live Example: https://demoqa.com/date-picker

driver.get("https://demoqa.com/date-picker");
JavascriptExecutor js = (JavascriptExecutor) driver;

WebElement dateInput = driver.findElement(By.id("datePickerMonthYearInput"));

// sendKeys on date pickers often doesn't work (read-only or masked)
// Use JS to set value AND trigger React events:
js.executeScript(
    "arguments[0].value = arguments[1];" +
    "arguments[0].dispatchEvent(new Event('input', {bubbles: true}));" +
    "arguments[0].dispatchEvent(new Event('change', {bubbles: true}));",
    dateInput, "05/26/2026");

System.out.println("Date set: " + dateInput.getAttribute("value"));

💡 Why dispatch input/change events?

React/Angular don't notice raw value= writes. They listen to events. Firing input and change events makes the framework re-render correctly.

5.4 Framework Integration Methods

/** JS-click fallback when normal click is intercepted. */
public void jsClick(By by) {
    WebElement el = driver.findElement(by);
    ((JavascriptExecutor) driver).executeScript("arguments[0].click();", el);
    logger.info("JS-clicked: " + by);
}

/** Set value + trigger events (date/masked inputs). */
public void jsSetValue(By by, String value) {
    WebElement el = driver.findElement(by);
    ((JavascriptExecutor) driver).executeScript(
        "arguments[0].value=arguments[1];" +
        "arguments[0].dispatchEvent(new Event('input',{bubbles:true}));" +
        "arguments[0].dispatchEvent(new Event('change',{bubbles:true}));", el, value);
    logger.info("JS-set value: " + value);
}

/** Scroll container to bottom (AG-Grid/virtualized). */
public void jsScrollToBottom(By container) {
    WebElement c = driver.findElement(container);
    ((JavascriptExecutor) driver).executeScript(
        "arguments[0].scrollTop = arguments[0].scrollHeight;", c);
}

🎙 Interview Answer

"JavascriptExecutor runs JS in the browser via Selenium. I use it for scrolling (scrollIntoView), highlighting elements for reports, waiting for document.readyState, and as a fallback for clicks intercepted by overlays or for date inputs where sendKeys doesn't trigger React state. I avoid using JS click as a default because it bypasses real-user checks and can hide actual UI bugs."
