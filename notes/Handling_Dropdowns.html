1. A mental model: what is a "dropdown" really?

Restaurant menu analogy Imagine you walk into a restaurant. The waiter hands you a menu - that's the trigger. You read the menu, point at "Paneer Butter Masala", and the waiter closes the menu and notes your choice. A dropdown works exactly like that: open → pick → close → selection committed. Every type of dropdown - native, Bootstrap, custom - is a different menu design, but the same flow.

Browsers do not have one universal "dropdown" widget. The word "dropdown" is a UX term, not an HTML element. As a tester your first job is to ask: which kind of dropdown am I looking at? - because that decides which Selenium technique works.

Implementation HTML signature Selenium tool of choice
Native HTML select <select><option> org.openqa.selenium.support.ui.Select
Bootstrap / jQuery <button data-toggle="dropdown"> + <ul> Click + List<WebElement>
Custom Div <div role="combobox"> + <div role="listbox"> Click + waits + Actions / JS
Auto-suggest <input> + dynamic <ul> sendKeys + wait + click
Golden rule Use the Select class only when the outer tag is literally <select>. Using it on anything else throws UnexpectedTagNameException.

2. Anatomy of every dropdown - inspect like a pro

Open DevTools (F12) → Elements panel and click the dropdown trigger. Look at the outermost element of the popup. The outer tag tells you the type, full stop.

Anatomy of a native <select>

<select id="country"> <option value="in">India</option> <option value="us">United States</option> </select>

Anatomy of a Bootstrap dropdown

<div class="dropdown"> <button data-bs-toggle="dropdown">Select country</button> <ul class="dropdown-menu"> <li><a>India</a></li> <li><a>United States</a></li> </ul> </div>

Anatomy of a div-based custom dropdown

<div class="custom-select" role="combobox"> <div class="selected">English</div> <div class="options" role="listbox"> <div role="option">English</div> <div role="option">Hindi</div> </div> </div>
Pro tip In DevTools, hover over the dropdown popup with the inspector arrow. If the highlight shows a <select>, you're done - use the Select class. If it shows a <ul> or <div>, you'll write click-based code.

3. Type 1 - Native <select> Dropdown

3.1 Definition & how it works

The native HTML dropdown - the simplest of them all. It has a single <select> tag with <option> children. Selenium ships with a helper class - Select - that wraps this exact element type.

Why the Select class exists Native selects behave specially - the dropdown panel is rendered by the operating system, not by the browser DOM. You cannot click an <option> the way you click a button. The Select class abstracts this away.

3.3 End-to-End Example - Facebook signup birthday dropdowns

Scenario
Open Facebook's signup page and choose 15 August 2000 as the date of birth. Verify the values were committed by reading them back. We use a complete Page Object + Test class to mirror your existing OrangeHRM framework style.

Page Object: FacebookSignupPage.java

package com.orangehrm.pages;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.support.ui.Select;

public class FacebookSignupPage {
    private final WebDriver driver;

    private final By dayDropdown   = By.id("day");
    private final By monthDropdown = By.id("month");
    private final By yearDropdown  = By.id("year");

    public FacebookSignupPage(WebDriver driver) {
        this.driver = driver;
    }

    public void selectBirthDay(String day) {
        new Select(driver.findElement(dayDropdown)).selectByVisibleText(day);
    }

    public void selectBirthMonth(String month) {
        // value is "1".."12" - we use visible text for readability
        new Select(driver.findElement(monthDropdown)).selectByVisibleText(month);
    }

    public void selectBirthYear(String year) {
        new Select(driver.findElement(yearDropdown)).selectByVisibleText(year);
    }

    public String readSelectedDay() {
        return new Select(driver.findElement(dayDropdown))
                .getFirstSelectedOption().getText();
    }

    public int countYears() {
        return new Select(driver.findElement(yearDropdown)).getOptions().size();
    }
}

Test: FacebookDOBTest.java

package com.orangeHRM.test;

import com.orangehrm.pages.FacebookSignupPage;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.testng.Assert;
import org.testng.annotations.*;

import java.time.Duration;

public class FacebookDOBTest {
    private WebDriver driver;
    private FacebookSignupPage page;

    @BeforeMethod
    public void setUp() {
        driver = new ChromeDriver();
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
        driver.get("https://www.facebook.com/r.php");
        page = new FacebookSignupPage(driver);
    }

    @Test
    public void selectDateOfBirth_shouldCommitAllThreeFields() {
        page.selectBirthDay("15");
        page.selectBirthMonth("Aug");
        page.selectBirthYear("2000");

        Assert.assertEquals(page.readSelectedDay(), "15");
        Assert.assertTrue(page.countYears() > 100,
            "Year dropdown should list at least 100 years");
    }

    @AfterMethod
    public void tearDown() {
        if (driver != null) driver.quit();
    }
}
Why this design The Page Object hides the dropdown type. Tomorrow Facebook may rebuild this page with a custom React widget - the test class won't change, only the Page Object will.

4. Type 2 - Bootstrap / Lightbox Dropdown

4.1 Definition & how it works

Bootstrap is a CSS/JS library used by ~25% of all websites. Its dropdown is built from a <button> (toggle) and a sibling <ul class="dropdown-menu"> (panel). When the button is clicked, JavaScript adds a show class that makes the panel visible. The panel often floats above other content - hence the nickname "lightbox dropdown".

Vending machine analogy Native <select> is a vending machine: you press the button and the OS draws the menu for you. Bootstrap is more like a folding paper menu: pressing the button physically reveals more HTML that was already on the page but hidden. As a tester you have to interact with that revealed HTML directly.

4.2 End-to-End Example - LambdaTest Bootstrap playground

Scenario
Open the LambdaTest Bootstrap dropdown playground, click "Single Button Dropdown", and pick the option "Action". Verify the click happened by reading the URL fragment.

Page Object: BootstrapDropdownPage.java

package com.orangehrm.pages;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;

import java.time.Duration;
import java.util.List;

public class BootstrapDropdownPage {
    private final WebDriver driver;
    private final WebDriverWait wait;

    private final By toggle      = By.id("single-button");
    private final By menu        = By.cssSelector("ul.dropdown-menu");
    private final By menuOptions = By.cssSelector("ul.dropdown-menu li a");

    public BootstrapDropdownPage(WebDriver driver) {
        this.driver = driver;
        this.wait   = new WebDriverWait(driver, Duration.ofSeconds(10));
    }

    public void openDropdown() {
        wait.until(ExpectedConditions.elementToBeClickable(toggle)).click();
        wait.until(ExpectedConditions.visibilityOfElementLocated(menu));
    }

    public void selectOption(String wantedText) {
        openDropdown();
        List<WebElement> opts = driver.findElements(menuOptions);
        for (WebElement o : opts) {
            if (o.getText().trim().equalsIgnoreCase(wantedText)) {
                wait.until(ExpectedConditions.elementToBeClickable(o)).click();
                return;
            }
        }
        throw new NoSuchElementException(
            "Option not found: " + wantedText +
            " | Available: " + opts.stream().map(WebElement::getText).toList());
    }
}

Test: BootstrapDropdownTest.java

@Test
public void shouldSelectActionFromBootstrapDropdown() {
    driver.get("https://www.lambdatest.com/selenium-playground/bootstrap-dropdown-demo");
    BootstrapDropdownPage page = new BootstrapDropdownPage(driver);

4.3 The "lightbox" twist

Some Bootstrap dropdowns (especially with data-bs-popper) move the menu OUT of its parent and append it directly to <body>. XPath written relative to the trigger will fail. 

// Wrong - assumes the menu is a sibling of the trigger
By.xpath(".//ul[@class='dropdown-menu']//a[text()='India']");

// Right - locate from document root, only the visible menu
By.xpath("//ul[contains(@class,'dropdown-menu') " +
         "and not(contains(@style,'display: none'))]" +
         "//a[normalize-space()='India']");

5. Type 3 - Custom Div Dropdown

5.1 Definition & how it works

A fully custom dropdown built from <div>, <span>, and CSS. There is no helper class in Selenium for this. You drive it like a real user: click the trigger, wait for the panel, click the option you want.

This is the hardest type Custom dropdowns vary wildly between sites. Some animate, some virtualise (only render visible rows), some teleport the panel to <body>, and some need keyboard input (arrow + Enter). Learn to inspect carefully.

5.2 End-to-End Example - MakeMyTrip flight booking

Scenario
Open MakeMyTrip, dismiss the login popup, set "From" to Delhi and "To" to Mumbai, both via div-based auto-search dropdowns.

Page Object: MakeMyTripFlightPage.java

package com.orangehrm.pages;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;

import java.time.Duration;
import java.util.List;

public class MakeMyTripFlightPage {
    private final WebDriver driver;
    private final WebDriverWait wait;

    private final By loginCloseBtn = By.xpath("//span[@data-cy='closeModal']");
    private final By fromLabel     = By.xpath("//span[text()='From']");
    private final By toLabel       = By.xpath("//span[text()='To']");
    private final By searchBox     = By.cssSelector("input[placeholder='From']");
    private final By suggestList   = By.cssSelector("p.font14.appendBottom5");

    public MakeMyTripFlightPage(WebDriver driver) {
        this.driver = driver;
        this.wait   = new WebDriverWait(driver, Duration.ofSeconds(15));
    }

    public void dismissLoginPopupIfPresent() {
        try {
            wait.withTimeout(Duration.ofSeconds(5))
                .until(ExpectedConditions.elementToBeClickable(loginCloseBtn))
                .click();
        } catch (TimeoutException ignore) { /* popup didn't show this run */ }
    }

    public void selectFromCity(String cityName) {
        wait.until(ExpectedConditions.elementToBeClickable(fromLabel)).click();
        WebElement input = wait.until(
            ExpectedConditions.visibilityOfElementLocated(searchBox));
        input.sendKeys(cityName);
        clickSuggestion(cityName);
    }

    public void selectToCity(String cityName) {
        wait.until(ExpectedConditions.elementToBeClickable(toLabel)).click();
        WebElement input = wait.until(ExpectedConditions.visibilityOfElementLocated(
            By.cssSelector("input[placeholder='To']")));
        input.sendKeys(cityName);
        clickSuggestion(cityName);
    }

    private void clickSuggestion(String cityName) {
        wait.until(ExpectedConditions.visibilityOfElementLocated(suggestList));
        List<WebElement> suggestions = driver.findElements(suggestList);
        for (WebElement s : suggestions) {
            if (s.getText().toLowerCase().contains(cityName.toLowerCase())) {
                s.click();
                return;
            }
        }
        throw new NoSuchElementException("City not found: " + cityName);
    }
}

Test

@Test
public void shouldBookFlightFromDelhiToMumbai() {
    driver.get("https://www.makemytrip.com/");
    MakeMyTripFlightPage page = new MakeMyTripFlightPage(driver);

    page.dismissLoginPopupIfPresent();
    page.selectFromCity("Delhi");
    page.selectToCity("Mumbai");

    // No assertion library magic - just sanity check on the visible chips
    Assert.assertTrue(driver.getPageSource().contains("DEL"));
    Assert.assertTrue(driver.getPageSource().contains("BOM"));
}

6. Type 4 - Auto-Suggest Dropdown

6.1 Definition

An <input> whose suggestion list is built dynamically as the user types - Google, Amazon, jQuery UI autocomplete. Each keystroke triggers an AJAX call; the results re-render the list.

6.2 End-to-End Example - Google search suggestions

@Test
public void googleSuggestionListShouldContainSeleniumWebDriver() {
    driver.get("https://www.google.com");
    WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

    WebElement box = driver.findElement(By.name("q"));
    box.sendKeys("selenium");

    // Wait for at least one suggestion to render
    By suggestionLi = By.xpath("//ul[@role='listbox']//li");
    wait.until(ExpectedConditions.visibilityOfElementLocated(suggestionLi));

    List<String> texts = driver.findElements(suggestionLi)
        .stream().map(WebElement::getText).toList();

    Assert.assertTrue(
        texts.stream().anyMatch(t -> t.toLowerCase().contains("webdriver")),
        "Expected at least one 'webdriver' suggestion. Got: " + texts);
}

6.3 Common pitfalls

IssueWhyFix
List is empty when you read itYou read before the AJAX completedWait for visibilityOfElementLocated on the list
List re-renders mid-iteration → StaleElementReferenceExceptionEach keystroke rebuilds the listCapture texts first, then re-locate the matching <li> by text
Pressing Enter went to results pageForm was submittedClick the suggestion <li> directly, or arrow-down + Enter

7.2 Custom multi-select (chips/tags)

Built with checkboxes inside a popup or React-Select multi. After clicking options, each appears as a "chip" with an "x" to remove. There is no Select helper - you click each option, and click the chip's "x" to deselect. 

WebElement input = driver.findElement(By.cssSelector("#selectMenuContainer input"));
input.click();
driver.findElement(By.xpath("//div[text()='Green']")).click();
driver.findElement(By.xpath("//div[text()='Black']")).click();

// remove the Green chip
driver.findElement(By.xpath(
    "//div[contains(@class,'multi-value__label') and text()='Green']" +
    "/following-sibling::div")).click();

8. Type 6 - Cascading / Dependent Dropdown

8.1 Definition

When the options of dropdown B depend on what was selected in dropdown A. Examples: Country → State → City, From → To (filtered by routes).

The trap After picking value A, the second dropdown is rebuilt. Any WebElement you held becomes stale. Always re-locate the second dropdown after the first selection, and wait for it to be re-populated.

8.2 End-to-End Example - SpiceJet flight booking

Scenario
On SpiceJet, select "From: Bengaluru" then select "To". Notice that picking "From" filters which destinations are available. 
@Test
public void shouldHandleCascadingFromToCity() {
    driver.get("https://www.spicejet.com");
    WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(15));

    // 1. Open "From"
    driver.findElement(By.xpath("//div[text()='From']")).click();

    // 2. Pick Bengaluru
    By cityRow = By.xpath("//div[contains(text(),'Bengaluru')]");
    wait.until(ExpectedConditions.elementToBeClickable(cityRow)).click();

    // 3. The "To" panel auto-opens. Wait for its options to render fresh.
    By toOptions = By.xpath("//div[@data-testid='to-testID-origin']//div[contains(@class,'css-')]");
    wait.until(d -> d.findElements(toOptions).size() > 5);

    // 4. Pick a destination
    driver.findElement(By.xpath("//div[contains(text(),'Mumbai')]")).click();

    Assert.assertTrue(driver.getPageSource().contains("BLR"));
    Assert.assertTrue(driver.getPageSource().contains("BOM"));
}

8.3 Cascading <select> pattern

// 1. Pick country
new Select(driver.findElement(By.id("country"))).selectByVisibleText("India");

// 2. Wait until states are loaded (more than the placeholder option)
wait.until(d -> new Select(d.findElement(By.id("state")))
                  .getOptions().size() > 1);

// 3. Pick state
new Select(driver.findElement(By.id("state"))).selectByVisibleText("Karnataka");

9. Type 7 - Hidden / Disabled Dropdown

Some apps style the original <select> as display:none and render a custom UI on top. Selenium throws ElementNotInteractableException because the element is not visible. Three solutions:

Solution 1 - Interact with the visible custom UI

Preferred. Use Section 5 techniques on the on-screen widget.

Solution 2 - JavaScript Executor (last resort)

WebElement hidden = driver.findElement(By.id("country"));
((JavascriptExecutor) driver).executeScript(
    "arguments[0].style.display='block';" +
    "arguments[0].value=arguments[1];" +
    "arguments[0].dispatchEvent(new Event('change',{bubbles:true}));",
    hidden, "in");

Solution 3 - Un-hide via JS, then use Select

((JavascriptExecutor) driver).executeScript(
    "arguments[0].style.display='block';",
    driver.findElement(By.id("country")));

new Select(driver.findElement(By.id("country"))).selectByValue("in");

11. Best practices that prevent flaky tests

  1. Inspect first. Decide between Select / Bootstrap / Div before writing code.
  2. Never use Thread.sleep. Replace with WebDriverWait + an ExpectedCondition.
  3. Wrap dropdown logic in a Page Object method - selectCountry(String name). The test class shouldn't know how the dropdown is built.
  4. Centralise utility methods for div-based dropdowns (Section 12) so every page object reuses the same battle-tested code.
  5. Validate after selection. Read back and assert. Catches "click happened but selection didn't" silently.
  6. For multi-selects, deselect all before each test so tests are independent.
  7. Handle stale elements with ExpectedConditions.refreshed(...) when cascading.
  8. Log the available options when the desired one isn't found - so failure messages are diagnostic, not vague.

12. Reusable DropdownUtility class

Drop this into com.orangehrm.actiondriver (or a new com.orangehrm.utilities.DropdownUtility) and reuse it everywhere.

package com.orangehrm.utilities;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;

import java.time.Duration;
import java.util.List;
import java.util.stream.Collectors;

public class DropdownUtility {

    private final WebDriver driver;
    private final WebDriverWait wait;

    public DropdownUtility(WebDriver driver, Duration timeout) {
        this.driver = driver;
        this.wait   = new WebDriverWait(driver, timeout);
    }

    /** Native  by value attribute. */
    public void selectByValue(By locator, String value) {
        WebElement el = wait.until(ExpectedConditions.elementToBeClickable(locator));
        new Select(el).selectByValue(value);
    }

    /** Bootstrap or div dropdown - click trigger, wait, click option by text. */
    public void selectFromCustomDropdown(By trigger, By options, String wanted) {
        wait.until(ExpectedConditions.elementToBeClickable(trigger)).click();
        wait.until(ExpectedConditions.visibilityOfElementLocated(options));

        List<WebElement> opts = driver.findElements(options);
        for (WebElement o : opts) {
            if (o.getText().trim().equalsIgnoreCase(wanted)) {
                wait.until(ExpectedConditions.elementToBeClickable(o)).click();
                return;
            }
        }
        throw new NoSuchElementException(
            "Option not found: " + wanted + " | Available: " +
            opts.stream().map(WebElement::getText).collect(Collectors.toList()));
    }

    /** Auto-suggest: type into input, wait, click suggestion by text. */
    public void selectFromAutoSuggest(By input, By suggestions,
                                      String typeText, String wanted) {
        WebElement in = wait.until(ExpectedConditions.elementToBeClickable(input));
        in.clear();
        in.sendKeys(typeText);
        wait.until(ExpectedConditions.visibilityOfElementLocated(suggestions));

        for (WebElement s : driver.findElements(suggestions)) {
            if (s.getText().trim().equalsIgnoreCase(wanted)) {
                s.click();
                return;
            }
        }
        throw new NoSuchElementException("Suggestion not found: " + wanted);
    }

    /** JS fallback for hidden / problematic
